Batch Payments

Upload a spreadsheet of member payments and post them in one go. Each row needs a member number, a date, a reference and at least one amount. Every row is checked against the member register and against references already posted before anything is written.

1Choose a file

Excel (.xlsx, .xls) or CSV. The first row must be the column headings.

2Match the columns

Tell the system which of your columns holds what. Any column you map to a fund is treated as an amount for that fund, so a row can be split across several funds at once.

Amount columns

Map each amount column to the fund it belongs to. Leave a column unmapped to ignore it.
